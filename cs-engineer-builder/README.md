# CS Engineer Builder

A modern web platform to empower future engineers in Computer Science, Programming, Cybersecurity, and AI.

## Features
- Beautiful, animated home screen
- Firebase Authentication (Login, Signup, Forgot Password)
- User Profile management
- Modular topics for Programming, Cybersecurity, AI, and more
- Built with React + Vite + TypeScript

## Project Structure
```
/src
  /pages
    - Home.tsx
    - Login.tsx
    - Signup.tsx
    - ForgotPassword.tsx
    - Profile.tsx
  /firebaseConfig.ts
  App.tsx
  main.tsx
  index.css
```

## Setup
1. Install dependencies:
   ```
   npm install
   ```
2. Start the development server:
   ```
   npm run dev
   ```

## Firebase
- Configure your Firebase project in `src/firebaseConfig.ts`.
